# CNNA supplementary documentation

The supplementary tree mirrors the canonical DAG section hierarchy. Every one of the 145 nodes has a numbered directory derived from its `section_path`; documented nodes contain `DOCUMENTATION.md`, while not-yet-written nodes contain only a neutral `SECTION_STATUS.json` marker.

`supplementary.md` is generated from the documented node files in `derivation_order`. It is not an independently ordered document source. `MAIN_PAPER_SHA256.txt` binds the rendered supplement to the exact current main-paper PDF.

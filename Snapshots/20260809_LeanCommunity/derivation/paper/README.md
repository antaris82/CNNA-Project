# Main-paper and supplementary sources

`main/paper.tex` no longer contains a manually maintained node order. It imports `main/GENERATED_SECTION_STRUCTURE.tex`, which is generated from the canonical `NODES.tsv` derivation order.

Each DAG node owns one numbered main-paper directory and one numbered supplementary directory. Existing node text is stored as `SECTION.tex` and `DOCUMENTATION.md`; open documentation slots contain only `SECTION_STATUS.json` and do not claim completed prose.

`../supplement/supplementary.md` is regenerated by concatenating the existing per-node `DOCUMENTATION.md` files in canonical derivation order.

Both PDFs use the shared layout and metadata files, 14 mm side margins, date `5 August 2026`, Editor `Jan Seeck`, and the DRAFT markings.

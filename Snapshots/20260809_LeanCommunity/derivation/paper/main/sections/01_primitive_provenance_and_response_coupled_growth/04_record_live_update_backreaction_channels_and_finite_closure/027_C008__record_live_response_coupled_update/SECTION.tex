\cnnaNodeHeading{027}{C008}{Record/live response-coupled update}
\cnnaNodePlacement{1.4.1}{D1}

\paragraph*{Position and scientific role.}
C008 is the first state-transition boundary after the verified M003--M004
response/birth chain.  It does not choose a new steering law.  Instead it
applies the immutable M004 birth instruction to two already-existing relation
channels: the historical \emph{record} channel and the current \emph{live}
channel.  Both are derived state variables; neither is an additional input.

\paragraph*{Mathematical contract.}
Let $R_n$ and $L_n$ denote the current record and live lists, and let a canonical
M004 instruction $B_n$ contain three relation-update blocks:
\[
\begin{aligned}
  P(B_n) &:\ \text{parent/newborn birth pair},\\
  A(B_n) &:\ \text{strict-ancestor backreaction},\\
  S(B_n) &:\ \text{earlier-sibling backreaction}.
\end{aligned}
\]
C008 defines the append-only update
\[
  \boxed{R_{n+1}=R_n\mathbin{\|}P(B_n)},
  \qquad
  \boxed{L_{n+1}=L_n\mathbin{\|}
    \bigl(P(B_n)\mathbin{\|}A(B_n)\mathbin{\|}S(B_n)\bigr)}.
\]
Thus previously recorded birth data are never rewritten, while subsequent
backreaction is represented only in the live channel.  At the exceptional
bootstrap state $X_1$, both channels are initialized from the same already
derived C014/C005 bidirected relation pair; this coincidence is not promoted to
a later-time identity.

\paragraph*{Representative-independent application.}
M004 supplies a canonical instruction only modulo C006 exact-fraction value
semantics.  Accordingly C008 does not demand literal equality of raw fraction
representatives.  If two old channel pairs are equivalent entrywise and two
M004 instructions are \texttt{BirthInstructionSameValue}, then the two C008
outputs are again \texttt{RecordLiveChannelsSameValue}.  This is the exact
abstraction boundary needed for the M004$\to$C008 handoff.

\begin{cnnaInfoBox}{Record is not a snapshot of live}
The record channel is an append-only provenance history.  A later live state may
contain ancestor and sibling backreaction that was not present when an older
relation was born.  Copying the current live network back into record would
therefore erase the distinction C008 is designed to preserve.  In the formal
update, ancestor and sibling lists do not occur in the record equation at all.
\end{cnnaInfoBox}

The retained legacy growth path contains executable scalar mechanisms that can
change birth data without being functions of the measured pre-birth response
\(R_n(s_{n+1})\).  O001 classifies eight represented mechanism classes:
\[
 \chi=(\chi_{\rm rank},\chi_{\to},\chi_{\leftarrow},
 \chi_{\rm load},\chi_{\rm nonlin},\chi_{\rm scale},
 \chi_{\rm base},\chi_{\rm atten})\in\{0,1\}^8.
\]
The admission predicate is not heuristic:
\[
 \operatorname{Admissible}(X,s,R,\Sigma,\chi)
 \quad\Longleftrightarrow\quad \chi=(0,0,0,0,0,0,0,0).
\]
On this branch the obstruction record is erased and the output is exactly the
four-tuple \((X_n,s_{n+1},R_n,\Sigma_b)\).  Each nonzero component is rejected
individually; the complete legacy witness is rejected as a special case.

The executable audit is source-bound.  Python inspects executable AST nodes in
the retained legacy functions and ignores comments and docstrings.  Lean
formalizes the same eight-field presence record, proves preservation of the
four admitted fields, and proves one rejection theorem for every channel.  The
prefix-free root package containing this module was built successfully under
Lean~4.31.0 in the user-reported 26-job Core build.

O001 is therefore a closed implementation obstruction, not a universal no-go
theorem for every conceivable growth law.  It neither chooses the C015
transform nor proves M003 positivity.  Its downstream statement is narrower:
the active M004 constructor may depend on provenance support and on the
response-derived scalar, but not on any of the eight represented independent
mechanism classes.
